# COMP 211 Quiz 2 study guide

Unofficial, student-written study guide for UNC COMP 211 (System Programming), Quiz 2: floating
point, program memory, pointers, dynamic memory, 2D arrays, make and bash.

Site: https://bhabad.github.io/comp211-quiz2/

Read a short part, answer a few questions on it, move on. Progress is stored in your own
browser. The whole site is the single file `index.html`, so it also works offline.

These are original notes and practice questions, not course material. Slides, readings and
official practice problems are on Canvas.
